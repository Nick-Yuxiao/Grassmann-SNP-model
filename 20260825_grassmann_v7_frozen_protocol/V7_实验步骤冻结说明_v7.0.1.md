# V7 实验步骤冻结说明 v7.0.1

**冻结日期：** 2026-08-25  
**状态：** 科学步骤冻结；T00 已启动；远端执行等待服务器连接授权  
**适用范围：** masked-genotype headroom、算子特异性和长度 scaling。本文不恢复历史 phenotype-epistasis claim。

## 1. 冻结原则

1. 冻结设计与运行时展开分离。`GRID_SPEC.v7.0.1.yaml` 是科学设计源；A2/A3 必须由已签名 verdict 生成新的 resolved TSV，禁止改写源文件。
2. 每个 resolved TSV 必须记录 source hash、verdict hash、展开行、删除行、运行数和自身 hash。
3. `Delta = NLL_comparator - NLL_candidate`，正数表示 candidate 更好。
4. 确认性推断以 data seed 为独立单位。每个 cell 使用 5 data seeds x 2 init seeds；先在 data seed 内对 init 求均值，再按 5 个 data seeds 配对推断。
5. Gate 只有 `GO`、`NO_GO`、`INCONCLUSIVE` 三态。INCONCLUSIVE 只允许追加一个预先冻结的 seed tranche；仍不确定则保守归为 NO_GO。
6. random/contiguous 是诊断 mask；`ld_block`、`within_chrom_longrange` 和 `cross_chrom` 是 headroom 裁决 mask。

## 2. 冻结常数

| 名称 | 数值 | 单位 | 用途 |
|---|---:|---|---|
| `delta_min` | 0.010 | nats/masked-token | 最小实际优势 |
| `delta_NI` | 0.010 | nats/masked-token | A3 非劣界 |
| `delta_LD` | 0.010 | nats/masked-token | 相对 closed-form LD reference 的最小优势；符号独立，数值恰与 `delta_min` 相同 |
| `overfit_thr` | 0.010 | nats/masked-token | A0 tiny-set 过拟合阈值 |
| `pc_control_thr` | 0.005 | nats/masked-token | true-PC 相对 shuffled-PC 最小优势 |
| `leak_accuracy_tol` | 0.010 | accuracy | 泄漏探针高于 chance 的容许量 |
| `resume_param_tol` | 1e-6 | max absolute parameter delta | 断点恢复确定性 |

同值常数仍保持独立名称，禁止全局字符串替换。

## 3. 阶段顺序

### P0 / T00-T04

- T00：在实际 RTX 5090 上建立 Python >=3.10、PyTorch >=2.7、CUDA 12.8+、`sm_120` 可用环境。
- T01：签署真实数据或 `1KGP+HGDP chr22 + 合成扩增` 数据分支，并生成 panel manifest。
- T02：核验本文件常数与指标方向，不再根据实验效果调整。
- T03：对 `L=8192` 和显存允许的最大 L 做 100-step 端到端 profiler。
- T04：仅用实测 GPU 小时建立 Compute Contract；需求不得超过已确认容量的 80%，另留 2 倍工程余量。

### V7-0 / A0

实现数据管线、五类 mask、三模型、双公平口径、断点续跑和 resolver。A0 同时阻断检查 tiny-set 过拟合、mask 泄漏、allele harmonization、断点确定性、PC 溯源、有限梯度、参数/FLOP 计数及 profiler/OOM。

### A1 / Headroom

- chr22：random/contiguous 仅做 matched-parameter 诊断；`ld_block` 与 `within_chrom_longrange` 同时做 matched-parameter 和 matched-compute 确认。
- 双染色体：`chr1 density-matched + chr22` 的 cross-chrom mask 同时做两个公平口径，并加入 shuffled-PC。
- `closed_form_ld_imputer` 是 classical reference，不称 Bayes floor。
- `ancestry_only_reference` 只回答祖源信息是否已解释跨染色体表现，不称 Bayes upper bound。

单个 mask 的裁决：两种必需公平口径均满足 `LCB > delta_min` 才为 GO；任一必需口径满足 `UCB <= delta_min` 则该 mask 为 NO_GO；其他为 INCONCLUSIVE。scope 只要一个确认性 mask GO 即 GO；所有确认性 mask NO_GO 才为 NO_GO。

### A2 / Operator specificity

resolver 只对 A1 判定为 GO 的 mask family 展开六个算子和两个公平口径。主比较固定为 `op_wedge_norm` 对 `op_bilinear_learned`；fixed random 仅为弱对照。没有 GO family 或没有已签署 GPU/存储合同时不启动。

### A3 / Scaling

resolver 将每个 A2 存活算子逐一展开，与 `local_attn_gpc` 分别比较。长度固定为 32768、131072、262144、524288；524288 是 held-out，不参与算子选择或 slope 模型选择。

只有以下四条同时成立才放行更大 L：交互斜率 CI 在有利方向排除 0；优势在 held-out 最大 L 实测复现；预注册计算所得 `L_star` 落在已签数据和算力内；两公平口径同向且当前精度满足 `delta_NI`。Gate 失败时仍保存 `L_star` 诊断值，但不得把它报告为扩容依据。

## 4. 5090 资源边界

用户已确认可使用 RTX 5090 服务器，这构成使用授权，不等于容量合同。T00/T03 必须实测 GPU 数量、显存、驱动、Python、调度器、可用磁盘和端到端吞吐，T04 才能签署容量。旧项目的 51-103 小时估算不属于本 V7 harness 的测量结果。
