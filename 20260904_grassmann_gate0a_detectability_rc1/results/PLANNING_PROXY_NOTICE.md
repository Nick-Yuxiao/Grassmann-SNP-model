# PLANNING PROXY result boundary

_Every result in this directory is a planning proxy. It uses no real genotype or phenotype and is permanently ineligible as formal Gate 0A evidence._

---

## What these numbers are

Power and false-positive rates for the Gate 0A decision procedure (per-regime paired-difference percentile-bootstrap CI, one-sided lower bound > 0), as a function of the true effect `Δ`, the replicate count `R`, and the replicate-level SD `σ` of the paired `R²_genetic` difference.

## What they are not

They are not Gate 0A results, not method comparisons, not biological evidence. `σ` is a **planning axis** — the real value is unknown until a panel is bound. The replicate count `R` may only be fixed for the real Gate 0A run after a small real-panel pilot pins `σ` and the row is read off this table. If `σ` turns out large, no gridded `R` suffices and `R` must be increased — the margin `0.005` is never lowered.
