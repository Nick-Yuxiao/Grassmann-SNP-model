# Deep branch 设计备忘录：G2PT 对照下的理论推演

**日期：** 2026-09-21　**状态：** rc0
**配套：** `G2PT_BASELINE_SPEC_DECISION.md`、`../configs/g2pt/CONFIG_FROZEN.json`

本文件固化一次推演的结论，供后续设计决策引用。对象是 gene-centric common/rare dual-path Deep branch 与 G2PT 的对比。

---

## 1. 一条硬约束：G2PT 的数据里没有稀有变异

v2 Methods p13 原文：参与者 "had been genotyped with **SNP arrays**"，共 203,126 个 SNP。**array 数据基本不含稀有变异**——探针按常见变异设计，MAF < ~0.5% 的位点要么没打，要么 imputation 质量不可用。

所以 rare path **不可能跑在 G2PT 的同一份数据上**，它需要 UKB **WES**（v2 参考文献里引的 Backman et al. 是 394,841 exomes）。那是 UKB 另一个数据层级，独立申请、独立下载、独立 QC。

**排期含义：common 路与 rare 路是两条独立的关键路径，rare 那条更长。** 已并入 `../FEASIBILITY_AUDIT.zh-CN.md` §7.1 的 UKB 清单。

---

## 2. 参数预算：预训练恰好打在 G2PT 最脆弱的一块

按论文配置（d=64, h=4, 5 个独立传播层, 253 基因, 20 系统）重建：

| | p=1e-8（2,429 SNP）| p=1e-5（5,510 SNP）|
|---|---|---|
| **SNP 嵌入表** | 310,912（**74.9%**）| 705,280（**87.1%**）|
| gene + system 嵌入 | 17,472（4.2%）| 17,472（2.2%）|
| 5 层 HiGT 注意力权重 | 81,920（19.7%）| 81,920（10.1%）|
| 合计 | ~415K | ~810K |
| **n / params** | **1.02** | **0.52** |

> 这是按 Methods 描述重建的量级估计，不是实际 `count_parameters` 输出。

两个推论：

**(a) G2PT 并不处在"样本远多于参数"的安逸区间**（n/params ≈ 0.5–1.0），正则化确实重要。

**(b) 但参数的 75–87% 全在 SNP 嵌入表，而 ontology 约束的是注意力层（10–20%）。** 注意力权重矩阵是 d×d，**与 token 数无关**——253 个基因和 2,530 个基因的 Wq/Wk/Wv/WO 参数量相同。**所以 ontology 不是在省参数，它限制的是函数类。**

**这是本方案最强的理论立足点**：G2PT 的 SNP 嵌入表是**纯靠表型信号从零学的**，而预训练可以用无标签基因型（全部参与者 × 全部 SNP，不需表型）去摊销那 75–87%。

---

## 3. 同一论证的反刃

- **目标函数错配**：预训练优化的是基因型结构重建（LD/haplotype），不是表型预测。64 维里编码的 LD 上下文可能与 TG/HDL 的效应方向大面积正交。
- **本项目已有的负面先验**：`../../../README.zh-CN.md` 记载，当前 Grassmann memory 在相同 16-byte 预算下被 aligned PCA 在 **8/8 个域**稳定支配，**损失的正是"有符号、位置对齐的系数"**——而 additive genetics 需要的恰恰是有符号的位置对齐效应。
- **标签不稀缺**：TG/HDL 在 UKB 有 42 万标签、5 千个输入 SNP。预训练迁移的理论收益随标签量增加而衰减。**这是预训练最不占优的地形。** 若要让"representation 有增量价值"最有机会成立，应放在标签稀缺处测：罕见表型、小队列、跨祖先迁移。

结论：C1 不是前提，是**必须被正面检验的主命题**。

---

## 4. ontology 在做一件容易被忽略的事：假设空间裁剪

G2PT 的上位效应搜索（v2 Methods p16）是一个层层收窄的漏斗：top-20 系统 → 系统内注释基因的 SNP → 卡方筛（注意力 top/bottom 10% 分层）→ SNP 对交互检验 → BH 校正 → 排除 <1 Mb 的对。最终报 40 个交互，是在被生物学先验切小的假设空间里做的校正。

去掉 ontology、让 gene↔gene 自由 attention：253 个基因 = **~32,000 对**；下沉到 SNP 层，1,395 个 SNP = **~97 万对**。注意力可以排序，但**注意力不是检验统计量**，它没有零分布。

**准确的说法：ontology 同时承担归纳偏置与假设空间裁剪两个角色。去掉它，第二个角色必须另找东西补上。** 本方案目前只处理了第一个。

> v2 Supplementary 含消融表（完整模型 vs 去 system / 去 system+gene / **去层次连接** / 去 SNP→gene 映射），"去层次连接"几乎就是 C3 的对照。**动手前先读。** 预测：预测性能损失很小甚至持平，ontology 的价值在可解释性与上述漏斗——但这是预测，要拿数据验。

## 5. 稀有路径的增量能不能被看见（最易翻车处）

设携带者比例 π，携带者内标准化增益 μ_c/σ_c，nested CV 单折测试集 n = 84,778。关键变量 **k = 非携带者预测扰动的 sd / 携带者真实增益的 sd**：

| π | 携带者 | 效应 | k=0（完美配对）| k=0.5 | k=1.0 | k=2.0 |
|---|---|---|---|---|---|---|
| 0.5% | 424 | 0.2 | **t=4.1** | 0.6 | 0.3 | 0.1 |
| 2% | 1,696 | 0.2 | **t=8.2** | 2.3 | 1.2 | 0.6 |
| 2% | 1,696 | 0.4 | **t=16.5** | 4.5 | 2.3 | 1.2 |
| 5% | 4,239 | 0.4 | **t=26.0** | 10.9 | 5.8 | 3.0 |

**注意 k=0 一列**：若两模型在非携带者上逐点一致，"全人群配对检验"与"仅携带者分层检验"的功效**在数学上恒等**（π 被 √n 抵消）。所以"稀有信号被人群稀释"这个直觉在**配对**检验下是错的。

**真正杀死功效的是 k > 0**：重训练一个带 rare path 的模型，共享参数被扰动、优化轨迹不同，非携带者预测也跟着变。k=1 时 t 从 16.5 掉到 2.3——**7 倍功效损失，从铁证掉到不显著**。

而 k>0 的最大制造者是 **B2：上游训练脚本没有随机种子**。

> **设计约束（从推演掉出来的，非拍脑袋）：**
> rare head 必须在结构上保证非携带者输出恒为零（零输入→零输出的残差头，不与 common 路共享可训练参数），并在**冻结的 common 模型上做残差训练**。这样才能把 k 压到 0。
> 若改为"先训联合模型再看 R² 涨没涨"，很可能得到假阴性。

## 6. 方案内部的一处不一致

自我定位是"比 G2PT 少一层 prior"（去掉 ontology）。但 SNP→gene 用的是

$$z^{common}_{ig}=\sum_j a_{jg}\,\alpha_{ijg}\,h_{ij}$$

其中 $a_{jg}$ 是 eQTL effect size / fine-mapping PIP 的**乘性权重**；而 G2PT 用的是 cS2G ∪ GTEx ∪ nearest-gene 的**二值边集**，权重全交给 attention 学。

**这一步的先验比 G2PT 更强，不是更弱。** 且 GTEx v7 的 eQTL effect size 在几百供体上估计、组织特异，作为乘性权重等于把这份噪声注入每个个体的每个 gene token。

**建议：** 把 $a_{jg}$ 降级为 attention 的**加性 bias 或初始化先验**，即 $\alpha_{ijg}\propto\exp(\text{score}_{ijg}+\log a_{jg})$——证据强的边起点高，但模型能推翻它。另：eQTL 覆盖不到 coding variant，G2PT 的三源并集（含 nearest gene）正是兜底，别在"做干净"时丢掉。

## 7. 一个应当直接沿用的 G2PT 设计

**zygosity-specific 模块**：G2PT 对 z ∈ {hetero, homominor} 用不同的 HiGT 模块，纯合主等位视为参考态不参与传播（v2 Methods p15）。这是显隐性效应的显式编码，结构上免费。

若 encoder 把 dosage 当标量输入，**这个性质会丢**。需专门检查。

## 8. 三个主张 × 基线变体

三个主张**定义不变**，只增加一个 `baseline_variant` 轴（见 `G2PT_BASELINE_SPEC_DECISION.md`）：

| | 主张 | 对照组 | 外部证据 | `baseline_variant` |
|---|---|---|---|---|
| **C1** | contextual embedding > raw dosage | 同架构同路由，输入换 raw dosage | **偏负面**（本项目 Grassmann vs aligned PCA 8/8）| 不适用（内部对照）|
| **C2** | rare burden 在 common 之上有增量 | common-only，**携带者分层 + k=0 设计** | **正面**（RICE）| 不适用（内部对照）|
| **C3** | 学出的 gene↔gene > 固定 ontology | 同模型 + ontology mask | **待查**（v2 Supp 消融）| **A / D 都要报** |

任何"相对 G2PT 提升 X"必须写明 `vs G2PT-code-faithful (arm A)` 还是 `vs G2PT-paper-faithful (arm D)`；若两者确认不一致，**两个都报**。

## 9. 战略结论（本备忘录最重要的一段）

C2 是三者中增量最确定的（RICE 已证），但**它恰恰与本方案的 foundation model 关系最小**——gene burden 从 annotation 算出，根本不经过 pretrained encoder。

**若三条一起上，很可能得到"整体优于 G2PT"的结果，而增量全部来自 rare path，C1 的真实贡献被掩盖。** 而 C1 正是本项目长期在追的问题。

**建议的实验顺序是反直觉的：先做 C1，在没有 rare path 的条件下把 pretrained embedding 相对 raw dosage 的条件增量测干净。** 理由：它便宜（不需要 WES）、结论硬、且若为负，整条 Deep branch 的设计都要改。用 rare path 的确定增量去垫底，只会推迟你知道答案的时间。

---

## 10. 总判定

**有增长空间，理论立足点比"照搬 G2PT"扎实**——核心是 G2PT 75–87% 的参数在一个纯靠表型从零学的 SNP 嵌入表里，而预训练正是用无标签数据摊销这块。这是真问题。

但增长不在原方案强调的地方：

- **去掉 ontology**：预测上大概率中性（参数不在那儿），代价是丢掉检验漏斗。收益被高估。
- **pretrained context**：打在正确位置，但目标函数错配 + 已有负面先验 + 42 万标签的地形，是预训练最不占优的场景。
- **rare path**：增量最大、最可能被评估方法自毁（k>0 → 7 倍功效损失），需要独立的 WES 数据路径，且与真正想问的问题关系最小。
