原因：bioRxiv 该预印本每页页脚写明 *"All rights reserved. No reuse allowed without permission."*，把它提交进 git 仓库等于再分发。审计需要的内容已全部抽进上一级的 `PAPER_SPEC.zh-CN.md`（那是我们自己的摘录与结构化整理，不是原文复制）。

需要原文时自行放置于此，文件名约定：

```
paper/G2PT_biorxiv_v2_20250411.pdf   # DOI 10.1101/2024.10.23.619940, v2
paper/G2PT_biorxiv_v3_20260115.pdf   # v3，含 LDL / T2D / 跨人群结果（尚未获取）
```

本目录除本说明外的内容已在 `.gitignore` 中忽略。
